# Contributing

Issues and pull requests are welcome.

## Writing style

Write new or changed text in ASD-STE100 Simplified Technical English:

- Short sentences (max 20 words for instructions, 25 for descriptions).
- Active voice.
- One instruction per sentence.
- Use "must" for obligations. Do not use "should".

Keep the existing terms: ubiquitous language, probe, decision record (ADR), C1/C2 views, blueprint, build/probe/spike ticket, blind review, quality locks, autonomy levels, and the ACF cycle (Define, Blueprint, Build, Verify, Learn).

## Pull requests

1. Describe the change and the reason.
2. Check relative links.
3. Do not put project-specific language or decision records into `acf/`. Put samples in `examples/`.
